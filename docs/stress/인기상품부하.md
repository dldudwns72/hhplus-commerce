## 개요

- 1,000,000 만건의 주문 상품에 대해 인기상품 조회 시 유저가 몰릴 경우를 대비한 부하 테스트 진행

## STEP 19

### 부하 테스트 진행을 위한 구성

1. K6
    - script 를 통하여 API 성능을 축정할 수 있는 부하 테스트 생성 도구
2. InfluxDB
    - K6에서 수집된 성능 지표들을 시계열 데이터 형태로 저장하고 관리하기 위한 도구
3. Grafana
    - Grafana 는 InfluxDB에 저장된 성능 데이터를 시각화하는 도구로, 결과를 쉽게 해석할 수 있도록 다양한 대시보드와 그래프를 제공해주는 도구

#### 부하테스트 흐름

- 부하 테스트 실행: k6는 스크립트를 실행하여 웹 서버 또는 API에 부하를 주고, 성능 데이터를 생성합니다.
- 데이터 수집: k6는 실시간 성능 데이터를 InfluxDB에 저장합니다.
- 데이터 시각화: Grafana는 InfluxDB에서 데이터를 가져와 대시보드에 실시간으로 시각화하고, 이를 통해 테스트 결과를 쉽게 확인하고 분석합니다.

### 목적

- 상품 주문 목록 데이터에 대해 상위 5개 조회를 진행하는 기능에 있어 유저가 단기간에 몰렸을 경우 부하 여부 체크 및 개선 목적

### 테스트 시나리오

1. 10초 동안 10명의 유저에게 요청
2. 30초 동안 50명 유저까지 도달
3. 20초 동안 다시 10명 요청으로 감소

### 부하 테스트 실행

```
docker run --rm -v /{path}/hhplus-commerce/scripts:/scripts grafana/k6 run /scripts/popular_product_test.js
```
